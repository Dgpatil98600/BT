# Assignment   - Blockchain + Practical Set


Each assignment includes:
- Simple code implementation
- Comments in code
- A detailed README with theory + practical explanation + expected output

## Folder Structure
- `assignment_1` - Simple blockchain with hashing and linked blocks
- `assignment_2` - Chain verification and tampering detection
- `assignment_3` - Wallet key pair simulation
- `assignment_4` - Transaction + double-spending prevention
- `assignment_5` - Deploy HelloWorld contract on Ethereum testnet
- `assignment_6` - Token transfer smart contract and execution
- `assignment_7` - Bitcoin block structure + Merkle root computation
- `assignment_8` - Proof-of-Work mining
- `assignment_9` - PKI identity infrastructure (educational simulation)
- `assignment_10` - Small DApp interaction with deployed contract
- `assignment_11` - Smart contract search engine
- `assignment_12` - AI-powered threat detection using blockchain logs

## Quick Start
For pure Python assignments (1,2,3,4,7,8,9,11):
```bash
python <file_name>.py
```

For Ethereum assignments (5,6,10):
```bash
pip install web3 py-solc-x python-dotenv
```
Then set `.env` values as described in each assignment README.

## Important Note
Some assignments use simplified educational cryptography to focus on concepts.
For production systems, use audited libraries and full security practices.
